# Changelog - v1.6.0

> 发布日期：2026-11-12

**配套：lianwall / lianwalld 5.6.0。**

## 通信与界面状态

- 请求有期限；断线、非法响应和类型不匹配时完成等待并重同步，不自动重放变更命令。
- 初始快照、主动状态推送与带 ID 的普通查询正确区分；迟到回执不结束新操作。
- 仪表盘、托盘与图库共享壁纸操作状态，等待匹配回执，结果未知时明确提示。
- 设置、状态与图库查询合并刷新意图，旧快照不能覆盖新事件，修复锁定状态重复反转。
- 调度快照更新倒计时，断线清空；成功连接后不再自动拉起用户主动停止的 daemon。
- 托盘重启等待旧 socket 释放，替代固定 200ms 延迟；新增 `--socket PATH` 并按端点区分单实例。

## 缩略图与本地设置

- 源文件修改/删除后重新核对缓存，损坏缓存重建；同键生成去重、JPEG 原子保存，写失败仍可显示内存结果。
- 修复内存预算更新与工作线程退出资源生命周期；取消等待/视频任务更及时。
- 新版磁盘缓存软上限 512 MiB / 4096 项；仅清理本程序新版缓存文件，旧目录暂不自动删除。
- 配置与缓存遵循 XDG；旧 HOME 设置按需原子复制，保留原件，迁移失败继续读取旧路径。

## 升级与验证

- 静态参数属性及 API 改为 `awww_args`，请与 daemon 5.6.0 配套更新。
- 增加可选 Qt Test 构建；35 个行为用例覆盖通信、配置/模型竞争、重启与缓存，另通过离屏实际启动测试。
- Release 由仓库根目录 `build.sh` 构建；脚本明确重新配置 Release，避免复用 Debug cache。
- 当前主要维护 Linux/Hyprland；其他环境及大图库长跑表现不作完整兼容承诺。
