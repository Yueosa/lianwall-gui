# LianWall-GUI 2.0.0

发布日期：2026-11-15

## 功能与修复

- 重写桌面界面：顶部五页导航、固定轮换控制栏、Material配色与新图标。
- 接入原生引擎状态、输出发现和真实Hook列表，区分配置、准备中状态与实际结果。
- 设置支持Enter保存、Esc取消、请求中状态和错误回退；新增可选`--show`启动参数。
- 壁纸库支持合并图片/视频、路径搜索、时间排序，以及daemon持久收藏与使用统计；保存回执前不修改收藏，分页版本变化时重读，收藏变更通过显式订阅推送。
- 显存测试支持未保存命令、请求中状态和真实诊断，不修改壁纸/轮换或已保存配置。
- 日志页接入最近记录、严重程度筛选、文件目录和UTF-8原子导出；显示实际过滤器、环境覆盖、文件写入异常和丢弃计数。快速筛选保留最后一次选择，刷新失败保留最近有效记录，断线清空旧会话诊断。
- 补齐外部参数/IPC、输出手动配置、内置过渡帧率、启动模式和算法设置；参数按argv元素编辑，保留空格/引号/中文/空参数；只对内置引擎生效的设置按后端显示。
- 补齐中英翻译目录与占位符检查，修复初始/运行时托盘语言、加载系统Qt标准控件翻译；导航宽度适应英语标签，统一下拉框并修正深色主题搜索提示和排序框对比度。
- 修复算法小数被取整及保存后规范化值未显示的问题；新增离屏真实QML键盘/焦点与参数编辑回归。
- 修复缩略图取消任务的跨线程完成通知崩溃；切换壁纸不再重建整库缩略图。
- 修复新增四种统计排序未实际生效、临时断线清除收藏筛选的问题；补齐排序与取消任务回归测试。
- 桌面菜单入口显式打开窗口，PNG图标安装到pixmaps，并随安装提供许可证。
- 首页默认窗口改为1280×720，预览按横屏比例与可用高度布局；移除5/10/30分钟快捷设置。
- 统一悬停提示主题，修正显存测试与日志按钮间距，日志按钮可换行；未安装的外部引擎标明不可用并禁止选择。
- 修复终止GUI时连带关闭daemon、重开预览回到系统旧服务的问题：正常信号仅退出GUI，显式退出两者菜单保留；新增daemon可执行文件固定参数。
- 修复首页预览的循环尺寸约束与侧栏溢出，文件信息和状态与预览对齐。
- 本版Hook提供真实列表、配置打开与重载；编辑、试运行与执行历史留待后续版本。

## 升级与运行

- 请配套lianwall/lianwalld6.0.0，先停止旧daemon再启动新版。新GUI连接旧服务时不具备新接口。
- 内置引擎需在引擎页分别指定图片/视频的单个目标输出。外部播放器可选安装；未安装时按钮标明不可用。
- SIGTERM/SIGINT仅关闭GUI，显式“退出GUI与服务”菜单停止两者；窗口关闭仍隐藏到托盘。
- 旧GUI设置保留迁移规则。收藏与统计由daemon持久化，不依附缩略图；清理缓存不清收藏。
- 源码要求Qt≥6.10；本次x86_64二进制链接Qt6.12（含私有API），需匹配Qt6.12运行库。视频缩略图需要ffmpeg可执行文件。
- 默认1280×720，实际尺寸受合成器规则影响。已验证作者本机Hyprland；不承诺所有Wayland环境。

## 验证范围

三套Qt回归、真实原生图片/Vulkan视频联调、失败回退/重连/暂停倒计时、ASan/UBSan内存访问检查、三种实际窗口尺寸的预览比例与侧栏边界检查通过。未声称零泄漏或完成所有DPI/长期/其他合成器验证。
