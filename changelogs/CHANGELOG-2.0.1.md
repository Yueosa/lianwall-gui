# LianWall-GUI 2.0.1

发布日期：2026-11-19

## 功能与修复

- 首页将壁纸预览、文件信息和轮换操作放在同一页，默认窗口调整为 1080 × 640。显存双环展示整卡已用与可用容量。
- 壁纸库支持分别打开图片和视频目录，相同路径合并显示。修正缩略图显示、卡片操作按钮的对齐和点击区域。
- 引擎配置和运行状态改为纵向排列。自动化页可打开 Hook 配置，优先使用 kitty 和 nvim，也可交给桌面关联应用。
- 增加跟随系统主题和应用菜单重启服务入口。显存读取测试独立展示，日志设置可直接打开目录。

## 升级与运行

本版配套 LianWall 6.0.0，可单独升级 GUI。Arch Linux 用户可更新 `lianwall-gui-bin`。x86_64 二进制使用 Qt 6.12 构建。
